# Tanukarr 0.1.2

Tanukarr **0.1.2** is the first release published from the
`KvasFan/Tanukarr` repository and the `ghcr.io/kvasfan/tanukarr` package. On
October 17, 2026, shortly after 0.1.1 was published, GitHub suspended the
account that owned the previous namespace, so that repository, its releases
and its images became unreachable. This release carries the 0.1.1 application
unchanged in behaviour, with the repository, package and logo links moved to
the new namespace. It keeps the inherited database schema (253), the v3/v5
APIs, provider identities and every 0.1.1 feature. Back up the configuration
before upgrading; use a compatible configuration backup when restoring an
older image.

## Changes

- Repository, issue and licence links shown in the application (System →
  More Info, Swagger licence URL), the notification logos used by Discord,
  Gotify, Join, Apprise, Emby/Jellyfin, Telegram and Kodi, the iCal product
  identifier, `package.json` and the Docker image source label now point at
  `KvasFan/Tanukarr` and `ghcr.io/kvasfan/tanukarr`.
- The Docker workflow pulls the earlier 0.1.0 image for its populated-library
  upgrade gate from this repository's own package. A `main` build in a
  namespace without that package skips the gate once with a warning; a release
  tag still fails without it. The 0.1.0 image was re-published to this
  namespace for that purpose.
- Documentation: the README, Docker guide and documentation index describe the
  move; historical reports keep their original links even though those no
  longer resolve.

Application code, tests and fixtures are otherwise identical to 0.1.1; see the
[0.1.1 release notes](0.1.1.md) for the pending-queue fixes.

## Upgrade

Pull `ghcr.io/kvasfan/tanukarr:0.1.2` and recreate the container. No database
migration beyond schema 253 runs; 0.1.0 and 0.1.1 configurations start
directly. Existing deployments that reference the previous namespace keep
running their already pulled image but can no longer pull updates from it;
change the image reference to the new namespace.

## Installation and verification

Use the [Docker installation guide](../docker-installation.md). The published
image is `ghcr.io/kvasfan/tanukarr:0.1.2`; `latest` selects the tested
release. The [verification ledger](0.1.2-verification.md) records the checks
executed for this source and the hosted publication. This release must not be
described as vulnerability-free; the 0.1.0 security inventory remains the
latest recorded public-image scan.
