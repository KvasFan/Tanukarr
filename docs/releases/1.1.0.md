# Tanukarr 1.1.0

This release develops collections, artwork reliability and editable quality
policies for TV series, anime and movie sagas, while retaining the existing
provider identities, list filtering, search, download-client, import and
Jellyfin Connect features.

## Collections

- A full collection page replaces the grouped-library modal, with a backdrop,
  cover, description and separate season, movie and special cards.
- Each card opens the native entry and selected season, with pack search,
  episode search, monitoring and season settings.
- Collection search queries the saved native members and presents progress,
  results and failures per member without initiating downloads automatically.
- Collection settings edit shared names, profiles and monitoring. Native
  multi-season TV entries have a separate collection display title. Existing
  identifiers, episode numbers and saved folders remain intact.
- Canonical AniList/MyAnimeList collection presentation can come from the
  verified root ID even when only a later season is saved. Verified alternate
  catalogue IDs can supplement missing member artwork or descriptions.
- Thumbnail selection respects the available sizes at high display density
  and retries the original cover before showing a placeholder. Decoding has
  encoded-size, dimension, pixel and frame budgets.

## Quality policies

- Create, copy, rename and edit custom and standard quality presets using
  source, resolution, optional codec and a bounded title expression.
- Quality identities persist across restarts. Deletion retires an identity
  after active profile references are cleared, preserving file/history data;
  retired presets can be restored.
- Each quality profile has editable codec size factors. The requested defaults
  remain MPEG-2/x262 0.50, AVC/x264 1.00, HEVC/x265 1.67 and AV1 2.22.
  Physical download bytes and indexer size limits remain physical values.
- Release and imported-file evaluation use the selected profile's quality
  matching and factors. Older API updates that omit the new fields preserve
  saved settings.

## Integration and verification

The SDK, runtime and existing Microsoft package references move to the October
security patch, .NET 10.0.13 with SDK 10.0.402. A direct patched Pkcs reference
also overrides the older MailKit/MimeKit minimum. Dependency audit checks remain
enabled; the verification ledger distinguishes patched issues from remaining
dependency findings.

New isolated checks cover artwork recovery, custom qualities, genuine
qBittorrent configuration and generated-media collection folders. Jellyfin
checks exercise selected-library refresh modes, persistent one-minute ticks,
offline recovery and watched feedback using generated media and disposable
accounts. Public downloads and privately configured external accounts are not
claimed as tested by these fixtures.

The [upstream review](../upstream-audit-2026-10-14.md) records the fetched Sonarr,
Kakarotto, gaboy and ikatun heads and the retained dependency/workflow decisions.
The [verification ledger](1.1.0-verification.md) records executed checks, image
identity, publication state and remaining security findings. Earlier release
reports retain their own checkpoints.

## Installation and upgrade

Use the [Docker installation guide](../docker-installation.md) and preserve your
configuration and media mounts. Back up the existing configuration before
upgrading. Schema migrations 251 and 252 add quality criteria/profile factors
and the native collection display title. They do not move existing media or
change saved provider identities. Downgrading an already migrated database is
not supported; retain a compatible backup and previous image.

Read the [collection guide](../anime-season-groups.md),
[quality guide](../quality-and-codec-size.md), [metadata guide](../metadata-providers.md)
and [Jellyfin refresh/watched guides](../jellyfin.md) for configuration.
