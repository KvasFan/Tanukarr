The provider audit distinguishes account lists from catalogue metadata. AniList
supports native custom-list membership; MyAnimeList has its own account statuses
and list tags rather than AniList-style custom lists. Jikan is a public catalogue
metadata client, not a substitute for authenticated MyAnimeList account imports.
Provider-specific controls, credential requirements and pagination safeguards
are described in the [provider matrix](../library-tools.md#provider-capabilities).
AniList custom-list filters and MAL list-tag filters can use the full eligible
account universe when included membership names are empty. TMDB List, Trakt
List and MDBList require at least one explicit source, normalize older single
sources and use combined inclusions minus exclusions. Excluded source membership
is read before optional content filters. No live private account or third-party
uptime is inferred from source inspection.

## Security and deployment

The full C# Semgrep 1.180.0 scan ran 27 rules over 3,201 targets and returned 87 findings.
Triage recorded every location: 55 authentication-context flags and 32 SQL flags;
65 locations are byte-identical to the upstream base and 22 belong to earlier
fork changes. None intersects the 50 changed/new C# paths (33 production and
17 test files); all eighteen untracked C# files were included. This does not
declare the full repository free of security issues or call every finding a
false positive. Three historical migrations, 029, 030 and 033, contain genuine
stored-string SQL hardening candidates; they are not fixed by this release.
No live exploitation was attempted.

MAL's unsaved Test-to-Fetch credential handoff is process-local, with a one-day
cache lifetime. The native regression uses an actual second provider instance
and rejects reuse of a rotated refresh token. It does not promise recovery
after a restart before new credentials are persisted; a discarded Test may
require renewed authorization if the service invalidated the saved token.

The original scan reported five partial-parsing warnings, including MAL's
primary constructor. Its syntax-equivalent classic constructor passed the
targeted 27-rule rescan with complete parsing, zero errors and zero findings.
Four older partial-parsing limits remain in three fixtures and migration 225.
Those limits are retained rather than reported as complete static coverage.
