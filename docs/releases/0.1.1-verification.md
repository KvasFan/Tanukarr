# Tanukarr 0.1.1 verification ledger

This ledger records the checks executed for the 0.1.1 source on October 17,
2026, on the maintainer's workstation (Windows 11, 16 logical processors) and
its rebuilt WSL2 Docker Engine 29.9.1. It extends the
[October 17 local deployment ledger](../local-deployment-verification-2026-10-17.md),
which found and reproduced the two pending-queue defects, with the browser,
genuine-download, PostgreSQL and arm64 checks requested before publication.
Hosted publication evidence (exact public digest, assets, hosted gate reports)
belongs to the 0.1.1 publication report once the release workflow has run.
Earlier release reports keep their own source and image identities.

## Browser checks

External Playwright 1.64.0 with Chromium 156.0.8078.4 (Chrome for Testing)
installed in WSL outside the application source drove the packaged UI.

First run against image `6c02ae03…`: first-run account creation **4/4**,
backup button/task timing **11** outer checks with its browser receipt, and the
Jellyfin Connect editor **4** checks passed. The functional/security browser
scenario failed on two stale expectations of `docker/tests/ui-security.cjs`
(the Add Series source list, which has offered the combined entry, TVmaze, TMDB
Movie and OMDb since 0.1.0, and the AniList custom-list help text simplified in
1.0.2), followed by six cascading failures from the editor left open; the
collections GUI audit stopped at its version guard because `VERSION` had
already been raised to 0.1.1 while the image still carried 0.1.0. The helper's
expectations were updated to the current product; no application behaviour
changed.

## arm64

`docker build --platform linux/arm64` produced an aarch64 image in 97 seconds
because the UI and backend stages now run on the build host and cross-publish
`linux-arm64`. Under QEMU user emulation (`tonistiigi/binfmt`), the image
passed the **12-check smoke gate** (startup, UI, v3/v5 metadata, SQLite,
ffprobe, permissions, restart persistence) and the **19-check functional and
security gate**. This is an emulated check on an amd64 host, not an arm64
hardware test, and the release workflow still publishes `linux/amd64` only.
