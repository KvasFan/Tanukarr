# Tanukarr 0.1.4 verification ledger

This ledger records the checks executed on November 2, 2026 for the 0.1.4 source.
Hosted publication evidence for the tag belongs to the 0.1.4 publication report.

## Application code

The release commit changes no application source. Its application code is that of
`main` commit `60975bdeb`. It contains the collection-season search and Quality page
work (`39ae44120`, `e9e7420bf`), 19 upstream Sonarr fixes and 5 fork-source commits
picked with their authors, and one test correction for an upstream commit
(`5f9ad5817`).

### Local checks

The workstation has no .NET SDK, and its `node_modules` lacks the Linux native
bindings that ESLint and Vite need. The checks therefore ran in disposable
containers: `mcr.microsoft.com/dotnet/sdk:10.0.402`, the SDK pinned by
`global.json`, and `node:24-bookworm` on a clean copy of the tracked files with
`yarn install --immutable`. In both containers .NET and Node had to be restricted
to IPv4, because outbound IPv6 does not work there.

During verification, one failure was found and fixed before pushing.
`DatabaseRestorationServiceFixture.should_move_database_back_if_restore_fails`,
imported with upstream `460022a72`, failed only because this fork's test base
rejects undeclared error logs. The test now declares the logged error; the
restore behaviour is unchanged.

The checks also showed that the frontend uses `/api/v5` while the new codec
endpoints existed only in v3. The v5 endpoints were added (`e9e7420bf`). The
hosted quality UI gate (`docker/tests/quality-ui.cjs`) was updated for the
editable table and now saves and restores an HEVC factor through the UI.

### New regression coverage

- `CompleteSeriesReleaseParserFixture`:
  - collection-title releases taken from a real Nyaa result list for
    *Assassination Classroom* (`S02 MULTi …`, `(2015) - Season 2 (S02) …`) map to
    the Second Season member;
  - other members' seasons, multi-member packs, COMPLETE collection titles,
    collection absolute ranges, later years and disabled grouping are rejected;
  - the `[Exiled-Destiny] … Second Season [Dual Audio]` batch is accepted;
  - ikatun's bare-title cases are covered.
- `QualityProfilePartialSizeFixture`: one edited codec factor reaches every
  profile without changing the others; invalid families or values write nothing.
- `QualityDefinitionSizeResourceFixture` (v3 and v5): shared, mixed and default
  codec factors, and the bulk update call.
- `frontend/tests/qualityHourlyLimits.test.cjs`:
  - only the edited codec family is sent;
  - reverting a factor sends nothing;
  - mixed factors are shown as such;
  - dragging one slider thumb sends only that limit.

## Release preparation

The release commit sets `VERSION` and the Dockerfile default to 0.1.4, adds these
release notes and updates the README, FORK, CONTRIBUTING, the Docker guide, the
documentation index and CONTRIBUTORS. It changes no application source. The tag
run executes the light gate profile; its result, the public digest and the assets
are reported in the publication report.

## Not executed here

- No local Docker image was built.
- The container fixtures (browser, provider, download and upgrade gates) run only
  in the hosted workflow.
- The collection search was not run against a real library or indexer. The parser
  cases reproduce the release titles from the reported Nyaa page, and the hosted
  Nyaa and collection fixtures exercise the search path.
