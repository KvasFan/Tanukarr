# Tanukarr 0.1.3 publication

The **linux/amd64** release was published by the hosted workflow on
October 18, 2026 and independently checked the same day. The
[GitHub release](https://github.com/KvasFan/Tanukarr/releases/tag/v0.1.3) is
the repository's latest release and carries nine verified assets; the same
assets, image and release entry were mirrored to
[GitLab](https://gitlab.com/tirael8308/Tanukarr/-/releases/v0.1.3). The source
is [`cacb78b7`](https://github.com/KvasFan/Tanukarr/commit/cacb78b7cfe847ae3a228699b6ad0d4add264068);
the annotated `v0.1.3` tag resolves to that commit on both hosts.

## Security and remaining findings

No new public-image vulnerability scan was recorded for 0.1.3; the
[0.1.0 inventory](0.1.0-image-security.json) remains the latest executed scan
and this release must not be described as vulnerability-free. The tag ran the
light gate profile: the browser, provider/list, Jellyfin and genuine-download
gates ran in the full profile on `main` for the same application code
(run 39110439743), not on the tagged commit.
