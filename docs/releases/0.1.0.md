# Tanukarr 0.1.0

Tanukarr **0.1.0** manages TV series, anime and movie collections. It retains
the inherited database migrations, v3/v5 APIs, provider identities and features.
Back up the configuration before upgrading; use a compatible configuration
backup when restoring an older image.

## Changes

- First startup opens a graphical account-creation form. No temporary password
  is generated or printed. Existing accounts and explicit environment credentials
  retain their behavior; account creation requires a valid antiforgery token and
  is closed after the first account is created.
- Collection searches select a member immediately, search automatically and use
  their own result filter. Episode searches include undated and future episodes
  when explicitly requested; automatic acquisition keeps its aired-only policy.
- Collection season actions have consistent sizing. The title opens the season;
  the duplicate Open Season control is removed. Season Settings opens the complete
  editor with native season monitoring. Episode tables stay expanded. Manage
  Episodes opens for an empty season; Preview Rename requires an existing file.
- Reprocessing a managed file retains its episode-file identity so Apply updates
  the existing file. Episode refresh persists the owning catalogue's native
  episode IDs instead of dropping them at the database boundary.
- Artwork retries the cached original and then public HTTPS provider artwork
  before using a placeholder. A verified reciprocal side-story relation no longer
  prevents Tanya's main season/movie chain from forming a collection. Ambiguous
  relationships still require manual grouping.
- Quality choices, grouping, sizes and profile codec factors are managed from
  Settings → Quality. Profile editing retains profile policy and custom formats.
  Quality rows and the group-season field align with their labels.
- Metadata Source settings enable multiple catalogues and persist their order.
  Add New Series offers all enabled catalogues or a single source. Native results
  remain distinct; existing series keep their owning catalogue. TVmaze adds a
  key-free TV catalogue with native episode numbering, titles, dates and artwork.
- TMDB Movies and OMDb add native film catalogues and IMDb-ID lookup through
  their official APIs. Films use title/year naming and strict file matching;
  collection packs map each physical file to its saved monitored movie. Existing
  AniList/MyAnimeList film filenames and saved file mappings remain supported.
- Library Import searches enabled catalogues and retains native source/ID
  identities, with provider links and duplicate detection for each catalogue.
- Mixed collections have independent season, movie and standalone-special
  positions. Native multi-season entries reserve their complete display range;
  conflicting edits or metadata refreshes preserve the prior saved membership.
  Native season-zero specials keep their catalogue episode identities.
- Movie searches use a local result filter so saved TV pack preferences cannot
  hide unnumbered feature releases. Newznab/Torznab movie categories are configured
  separately from TV/anime categories.
- The image resizer uses maintained SkiaSharp packages. Docker adds a silent
  local healthcheck, removes unneeded setuid/setgid mode bits and updates available
  system packages. Maintained Yarn, ESLint, Stylelint and action runtimes replace
  obsolete tooling; lazy routes, complete timezone assets and bundled fonts build
  without the previous chunk/font warnings.
- Container startup rejects root/malformed user IDs, protects configuration
  permissions, handles ownership errors and avoids following ownership symlinks.
  Compose enables `no-new-privileges`.

## Installation and verification

Use the [Docker installation guide](../docker-installation.md). The published
image is `ghcr.io/kvasexpert/tanukarr:0.1.0`; `latest` selects the tested release.
Configuration and media mounts remain compatible. The
[publication report](0.1.0-publication.md) records the verified digest, source,
nine assets and executed verification.

The [verification ledger](0.1.0-verification.md) records executed checks, exact
source/image identities, failures, exclusions and security findings. Historical
test counts are not evidence for this build. The [October 12 report](legacy-0.1.0-verification.md)
retains its original source-qualified checkpoint.

See the [actual public-image inventory](0.1.0-image-security.json),
[maintenance verification](0.1.0-maintenance-verification.md) and publication
report for exact executed checks and remaining findings. The build-only
`braces` advisory has no published patched version; runtime OS findings are
reported separately. This release must not be described as vulnerability-free.
