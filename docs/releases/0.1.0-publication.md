## Security results and remaining findings

The [public image inventory](0.1.0-image-security.json) records the immutable
identity, verified Trivy 0.76.0 scanner/database/report hashes and complete RootFS.
It found **19 runtime OS vulnerability occurrences / 15 CVEs**: **14 Medium,
five Low, zero High and zero Critical**, with zero detected image-layer secrets.
This is an executed exact-public-image scan, not a candidate count or a claim
that the release is vulnerability-free.

The Docker configuration scan separately retains **DS-0002 High** because
startup prepares the configured account/config ownership before dropping
privileges. Actual checks verify the unprivileged process, zero capabilities,
no-new-privileges and absence of unnecessary setuid/setgid helpers. One
**High build-only `braces` advisory** remains: the final official package/advisory
check still reports version 3.0.3 without a patched version
([GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)).
Node/Yarn and that dependency are absent from the application runtime image.
These distinct findings remain visible and unsuppressed.

ImageSharp and its advisory suppressions were replaced with SkiaSharp and the
required notices. Actual disk/stdout Trace probes before report redaction prove
provider keys and generated salts are absent while real configuration writes
remain observed. A late test-evidence audit found that the old root-user
`! grep` PID1-environment assertion could also pass on procfs PermissionDenied;
it is not accepted as proof. A separate strict check on the exact public image
successfully reads PID1 as the app UID and confirms no locking override. Normal
and exclusively locked health reads return 0 silently; a bad-port control returns 1
silently. App writer locking remains enabled; the override is scoped to the
read-only health child. The canonical inventory records both the weak original
assertion and the executed strict replacement evidence.

## Scope and attribution

All media and libraries used for execution are generated, with owned disposable
configurations and local HTTPS catalogue fixtures. Downloads use only owned
torrent/web-seed payloads. No owner library was downloaded into, renamed, moved,
rescanned or upgraded. No live TMDB/OMDb credentials were supplied: provider
checks verify actual HTTP/JSON contracts and native identity behavior, not live
account access or current catalogue accuracy. GPU encoding, ARM runtime images,
arbitrary private indexer/provider accounts and additional browser engines were
not tested. Source/image secret scans do not cover arbitrary runtime volumes or
Git history. The SBOM is an inventory.

Original authors and co-author trailers remain preserved in Git and
[CONTRIBUTORS.md](../../CONTRIBUTORS.md). Implementation and verification used
OpenAI Codex based on GPT-6 with pinned
[wshobson/agents roles](https://github.com/wshobson/agents/tree/044b4b21f083948e69ec878a7b07c8d0951a6ffa).
