was published on **2026-10-14 at 06:32:19 UTC** with nine assets. All three
hosted workflows passed on the exact release source. The public image, downloaded
assets and fourteen runtime reports were independently verified. The preserved
local installation is running at `http://localhost:6970/` with existing login
credentials and `http://localhost:6970/series` as its library route.

## Protected local upgrade

The verified published image was deployed after a stopped-container configuration
backup with restricted Windows access and successful SQLite integrity checks.
The existing container identity, ports and configuration/media mounts were
preserved. No stale database backup was restored over current data.

Migration **250** added only `ImportLists.PreferredMetadataSource`, defaulting to
Automatic. All old protected columns and rows across **37 tables** matched the
backup. The only recorded raw table changes were `ImportLists` and `VersionInfo`;
there were no changed old-column fields. The verifier records raw hashes while
excluding documented volatile tables and narrow search bookkeeping fields from
its preservation comparison. This is not a byte-for-byte whole-directory claim.

Subsequent read-only checks confirmed **292 series**, **5,074 episodes**, **one
list** and **292 list items**. API v3 and v5 report Tanukarr **1.0.5**, core
**10.0.0.10489**, .NET **10.0.12** and schema **250**. Both APIs expose the new
preference; the existing list remains Automatic. Only the owner container remains.
The login redirects are expected because existing Forms authentication is enabled.

There are zero registered episode files and zero reported media bytes. This does
not inventory unregistered physical files or prove real media import/download.
The current import root is still `/tmp`, in the container's ephemeral writable
layer. Existing paths were not moved. Choose a persistent media mount before
real downloads. No Jellyfin notification or watched synchronization is configured
on the owner installation; those features were tested in disposable instances.

not provide a whole-repository security guarantee. No clean-dependency claim is
