## Security

The separately executed baseline scan of the 1.1.0 image found 54 vulnerability
occurrences: zero Critical, 21 High, 28 Medium and five Low. All High occurrences
concern ImageSharp 3.1.12. This baseline is not a scan of the new candidate.
The fixed major version's Release build requires a valid Six Labors license;
no license validation is bypassed. Final-image scan and remaining package details
will be recorded after building the exact candidate.

The first packaged candidate was separately scanned with Trivy 0.75.0:
54 occurrences, 20 distinct CVEs and 24 package/CVE pairs, zero Critical,
21 High, 28 Medium, five Low and zero secret matches. All High findings are
ImageSharp 3.1.12. OS findings have no advertised fixed version. The Yarn audit
reports three High build-tooling `braces` paths for CVE-2026-93687, with no
patched version; Node/Yarn are absent from the runtime image. A targeted Semgrep
scan ran 185 rules on 25 files with zero findings and one partial Dockerfile
parse warning (96.9% parsed). Trivy config retains the root preparation-stage
and absent HEALTHCHECK findings; actual privilege dropping is verified at runtime.
These are scoped checks, not a whole-repository or vulnerability-free claim.
