# Tanukarr 0.1.4 publication

The hosted workflow published the **linux/amd64** release on November 2, 2026,
and it was checked independently the same day.

- The [GitHub release](https://github.com/KvasFan/Tanukarr/releases/tag/v0.1.4) is
  the repository's latest release and carries nine assets.
- The source is [`73dd9702f`](https://github.com/KvasFan/Tanukarr/commit/73dd9702fd52ecdeb01d23da9e06d882f9373021).
- The annotated `v0.1.4` tag resolves to that commit.

**Not done:** the GitLab mirror. This workstation has no GitLab credentials, so the
commits, tag, image and release assets are not yet on
[gitlab.com/tirael8308/Tanukarr](https://gitlab.com/tirael8308/Tanukarr); see
*Remaining work*.

## Local checks of the published image

A disposable container was started from the registry-pulled `0.1.4` image with
no configuration and was removed afterwards.

| Check | Result |
| --- | --- |
| Startup | `/ping` answered |
| `GET /api/v5/qualitydefinition/codecfactors` | 18 codec families; HEVC 1.67 and AV1 2.22, neither mixed |
| `PUT` `{ "HEVC": 1.8 }` | All six default quality profiles report HEVC 1.8; AV1 stays 2.22 |
| `GET /api/v3/qualitydefinition/codecfactors` | Same HEVC 1.8 result as v5 |

No browser session, real library, indexer or download client was used with the
published image. The collection-season search is covered by the parser tests
and the hosted Nyaa and collection fixtures, not by a real indexer.

## Security and remaining work

- No new public-image vulnerability scan was recorded for 0.1.4. The
  [0.1.0 inventory](0.1.0-image-security.json) remains the latest executed scan,
  and this release must not be described as vulnerability-free.
- The tag ran the light gate profile. The browser, provider/list, Jellyfin and
  genuine-download gates ran in the full profile on `main` for the same
  application code (run 41451848100), not on the tagged commit.
- **GitLab mirror pending.** It needs the maintainer's GitLab credentials to:
  - push `main` and `v0.1.4`;
  - push the image to `registry.gitlab.com/tirael8308/tanukarr` (`0.1.4`, `latest`);
  - upload the nine assets to the generic package `tanukarr`/`0.1.4`;
  - create the `v0.1.4` release entry.
